# Принятые решения

## 2026-11-06 — рамка прототипа

- Единственный текущий стенд используется для разработки и демонстрации.
- Домен и HTTPS отложены по решению владельца.
- Внешние интеграции авторизации заменяются явно обозначенными заглушками.
- Реальные платежи, приглашения и последующие этапы не входят в текущую работу.
- Для прототипа сохраняется SQLite; PostgreSQL перенесён в подготовку боевого запуска.
- Медиабиблиотека получает локальный рабочий режим и конфигурационную готовность к S3; внешнее хранилище не активируется без отдельных ключей.
- Вместо одного универсального редактора используются специализированные редакторы страниц, квиза, планера и форм.
- Кабинетный кошелёк является бонусным и не представляет денежные средства.

## Дизайн

- Сохраняются Noto Serif для заголовков и Noto Sans для рабочего интерфейса.
- Палитра остаётся природной: бумажный фон, глубокий зелёный текст и действия, тёплые нейтральные разделители.
- Админка использует плотную рабочую компоновку: левая навигация, центральная рабочая область, контекстные действия без декоративных карточек ради карточек.
- Тонкие разделители, ясные статусы, крупные зоны фокуса и отсутствие обязательной анимации важнее декоративных эффектов.
