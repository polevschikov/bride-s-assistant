# Ключевые решения

## Рамка продукта

- **Единственный стенд REG.RU.** Прототип используется для разработки и демонстрации; отдельную тестовую среду сейчас не создавать.
- **Без домена и HTTPS.** Отложено владельцем; не подключать самостоятельно.
- **Этапы 1–4 завершены.** Реальные платежи (этап 5), конструктор приглашений (этап 6), роли и расширенное развитие (этап 7) не входят в текущий объём.
- **Демонстрационная авторизация.** Email, Яндекс и VK создают локальные сессии без внешних запросов; интеграции не имитируются как настоящие.
- **Один администратор без ролей.** Отдельный `ADMIN_ACCESS_CODE`, сессии в памяти процесса.

## Данные и инфраструктура

- **SQLite сохранён намеренно.** На одном стенде он уменьшает операционную сложность и поддерживает консистентные резервные копии. PostgreSQL перенесён в подготовку боевого запуска, а не признан ненужным вообще.
- **Схема и seed находятся в `server.mjs`/`content-seed.mjs`.** `INSERT OR IGNORE` не перезаписывает существующий контент. Migration runner пока не вводить без отдельной задачи.
- **Локальное файловое хранилище + S3-адаптер.** На стенде файлы работают уже сейчас; S3 включается только полным набором ключей. Не делать внешний S3 обязательным для прототипа.
- **Node.js раздаёт API и production `dist`, Nginx проксирует.** Это сохраняет один сервис и один порт приложения.
- **Ручной deploy из GitHub `main`.** CI/CD не существует; не описывать push как автоматическую публикацию.

## Целостность предметной модели

- **Заказ — исторический снимок услуги.** Последующее изменение названия/цены каталога не меняет старый заказ.
- **Клиентский планер — копия шаблона.** Публикация нового шаблона влияет только на новые проекты.
- **Черновик и опубликованный контент разделены.** Предпросмотр страниц требует admin-сессии; публичный API отдаёт только опубликованное.
- **Удаление не должно разрушать историю.** Используемая услуга скрывается, главная не удаляется.
- **Кошелёк — бонусы, не деньги.** Баланс вычисляется журналом, отрицательное значение запрещено; пополнения и вывода нет.

## Интерфейс и дизайн

- **Специализированные редакторы вместо одного универсального.** Страницы, квиз и планер имеют разные модели и отдельные редакторы.
- **Сохраняются Noto Serif + Noto Sans и природная палитра.** Бумажный фон, глубокий зелёный, тёплые разделители, авторские WebP.
- **Админка — рабочая компоновка.** Левая навигация, центральная область, ясные статусы и действия; без декоративных карточек ради карточек.
- **Тонкие разделители и ограниченная анимация.** Доступность и предсказуемость важнее декоративных эффектов.
- **Query-параметры вместо отдельного route tree.** Текущий SPA-подход сохранён для прототипа; не переписывать без необходимости.

## Документация и передача

- Новый агент работает только по задачам владельца и обновляет `docs/` в каждой задаче.
- Секреты передаются вне Git. В репозитории фиксируются только имена, расположение и назначение доступов.
- Не удалять шаблонные/временные файлы и не ротировать доступы без отдельной команды владельца.
